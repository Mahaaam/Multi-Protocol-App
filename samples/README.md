# Samples

Copy `credentials.example.json` to a private local path (never commit real values):

```text
client/secrets/credentials.json
src/DirectVpnLab/Assets/certs/credentials.json
```

Also place a private CA certificate trusted by the lab client at:

```text
src/DirectVpnLab/Assets/certs/ca.crt
```

Do not commit real keys, passwords, UUIDs, or certificates.
